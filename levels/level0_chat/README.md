# Уровень L0. Чат с LLM — «разговор с умным коллегой»

Самый доступный способ: открыли чат (ChatGPT / Claude / GLM-чат / Яндекс), вставили
код и вопрос, скопировали ответ в файл. Ноль инструментов, ноль настройки —
и максимум ручного труда.

## Как сделать (пошагово)

1. Откройте любой чат с сильной LLM.
2. Вставьте содержимое `levels/level1_api/prompts/task_full.txt`
   (задача + весь код библиотеки одним сообщением).
3. Скопируйте ответ модели в новый файл `test_ordercalc.py` в корне проекта
   (удалите markdown-ограждения ```python, если модель их поставила).
4. Запустите тесты руками:
   ```bash
   python -m pytest test_ordercalc.py -q          # пакет ordercalc должен быть рядом
   ```
5. Если тесты падают — скопируйте вывод pytest обратно в чат с просьбой исправить.
   Повторяйте, пока не надоест (обычно 1–3 круга).
6. Готовый файл положите в `results/runs/l0_chat/test_ordercalc.py`, чтобы
   оценка `evaluation/evaluate.py` увидела прогон.

## Что произошло с точки зрения процесса

Вы вручную выполняете роль **харнесса**: доставляете код модели (copy-paste),
доставляете результат запуска модели (terminal → чат), сохраняете артефакты.
Каждый круг — минуты человеческого времени, и ничто не гарантирует, что коллега
повторит ваш эксперимент с тем же результатом.

## Плюсы

- **Ноль порога входа**: не нужны ключи, скрипты, Python-окружение для модели.
- **Диалог**: можно уточнять («а добавь тесты на високосный год») — удобно.
- **Прозрачность**: видите каждый символ, который уходит модели и приходит от неё.
- Часто **бесплатно** (веб-интерфейсы).

## Минусы

- **Не воспроизводится**: результат зависит от чата, истории диалога, настроения модели.
- **Нет учёта затрат**: токены и стоимость не измерить (только глазами в интерфейсе).
- **Ручной труд**: 10–20 минут оператора на круг; ошибетесь при копировании — начнёте заново.
- **Контекст замусоривается**: через несколько кругов чат тащит всю историю, качество и цена растут.
- **Нет интеграции**: не встроить в CI, не запустить по расписанию.

## Когда использовать

Разовые вопросы, изучение новой библиотеки, черновики, обсуждение дизайна.
Как только задача становится повторяемой — переходите на L1.
