# Уровень L3. Топовый харнесс — «полноценный агент в вашем репо»

ZCode, Claude Code, Codex CLI, Cursor и подобные — это L2, доведённый до
продакшена: файловые инструменты (читать/писать/искать), полноценный bash,
много итераций, контекст-менеджмент (сжатие истории, субагенты), права
доступа, параллельность. Модель **сама** ходит по вашему проекту.

## Как сделать

1. Установите любой агент-харнесс (ZCode / Claude Code / Codex CLI / Cursor).
2. Откройте в нём корень проекта `ai_dev_ladder`.
3. Дайте задачу — текст ниже (это «золотой промпт» уровня):
   > Прочитай библиотеку `demo_project/ordercalc` (3 модуля) и напиши исчерпывающий
   > pytest-сьют в `results/runs/l3_top/test_ordercalc.py`. Импорты
   > `from ordercalc.<module> import ...`. Требования: тесты проходят на эталонном
   > коде, покрытие строк и веток максимально, есть граничные случаи и валидация
   > входов, параметризация. Сам запусти pytest и coverage, итерируй до зелёного
   > результата и высокого покрытия. Запрещено: смотреть `demo_project/variants/`
   > и `results/runs/ref/`.
4. Агент сам прочтёт код, напишет тесты, запустит, исправит, добьётся покрытия.
5. Оценка: `python evaluation/evaluate.py results/runs/l3_top`.

## Что получает модель по сравнению с L2

| Возможность | L2 мини-харнесс | L3 топовый |
|---|---|---|
| Инструменты | 1 (запуск тестов) | десятки (файлы, поиск, bash, git...) |
| Доступ к проекту | нет, код вклеен в промпт | да, сама читает нужные файлы |
| Итерации | ≤3 | пока не решит / лимит бюджета |
| Контекст | растёт без управления | сжатие, субагенты, выборочное чтение |
| Права/безопасность | нет | подтверждения, песочницы |

## Плюсы

- Наивысшее качество на задачах «в проекте»: агент итерирует до зелёного.
- Минимум человеческого труда: постановка — 2 предложения.
- Работает с кодовой базой любого размера (читает только нужное).
- Заметный выигрыш на сложных, многошаговых задачах.

## Минусы

- **Дорого**: десятки вызовов, каждый с растущим контекстом (токены ×5–20 к L1).
- **Нужен надзор**: агент может «обмануть» метрику (подогнать тест под баг,
  ослабить ассерт, пометить тест xfail). Ревью артефактов обязательно.
- Безопасность: агент исполняет команды — настраивайте права/подтверждения.
- Вендор-зависимость: промпты и механика различаются между харнессами.

## Когда использовать

Повседневная разработка: фичи, рефакторинг, тесты, дебаг в реальном репо.
Главный рабочий инструмент разработчика в 2026 году.
