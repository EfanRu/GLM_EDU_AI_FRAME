## Слайд 1. Обложка (тёмный фон)

**Заголовок:** Разработчик и AI: пять способов работы — от чата до мультиагента

**Визуал:** 5 цветных плашек L0→L4 (чат → API → мини-харнесс → топ-харнесс → MCP+агенты)

## Слайд 2. Методика

**Тезис:** одна задача, критерии зафиксированы ДО генерации
- Задача: pytest-сьют для `ordercalc` (3 модуля, 6 функций, краевые случаи) + 5 посеянных багов
- Прогоны: REF (человек), L0 чат, L1 API (GLM-5.3 и Flash), L2 мини-харнесс, L3 топ-харнесс, L4 MCP+мультиагент
- Метрики: Q1–Q5 качество (покрытие line/branch, 5/5 багов, прохождение на эталоне) · E1–E4 токены/время · Score
**Визуал:** лестница уровней L0→L4 + REF; сноска «CRITERIA.md, зафиксирован 2026-10-06»

## Слайд 4. Качество

**Тезис:** 100% покрытия и 5/5 багов на всех уровнях — различается надёжность, а не покрытие
**График:** `results/charts/01_quality.png`
**Ключ на слайде:** L1 GLM-5.3 сгенерировал неверный тест `split_payment(0,1)==[0]` — слепая
генерация об этом не узнает; L2 в той же ситуации исправил свой ошибочный тест сам после прогона pytest.

> Заметки: задача «легковата» (чистый код влез в промпт) — на legacy-проекте разрыв L1 vs L3/L4 больше.

## Слайд 5. Экономика токенов

**Тезис:** агентность стоит в разы дороже входа
**График:** `results/charts/02_tokens.png`
- L0/L1: ~1 900 входных — весь код в промпте
- L2: ×1.3 входа — каждая итерация тянет историю
- L3: самый экономный вход (1 767) — агент читает только нужное
- L4: ×12 к L1 — план гоняется между ролями; цена специализации
- Деньги: $0 (Flash, бесплатный тир) … $0.07 за прогон против 2–3 ч разработчика

## Слайд 6. Score против бюджета

**Тезис:** где точка оптимума
**График:** `results/charts/03_quality_vs_cost.png`

## Слайд 7. Время

**Тезис:** всюду минуты, не часы
**График:** `results/charts/04_time.png`
- Даже самый медленный подход (L4, 723 с) ~50× быстрее ручной работы REF (~2–3 ч)
- Итерации: L2 — 3, L3 — 3 (4 падения исправлены), L4 — 4

## Слайд 8. Сравнение моделей (ось L1)

**Тезис:** бесплатная Flash не уступила флагману на этой задаче
**График:** `results/charts/05_models.png`
- Flash: 100% прохождение, 100% покрытие, 5/5 багов, $0
- Флагман 5.3: быстрее (155 с vs 226 с), но оставил 1 неверный тест
- Локальный тир qwen2.5-coder:7b не прогонялся (нет GPU) — скрипт готов, SETUP.md §3
**Вывод:** переплата за флагман оправдана на сложных многошаговых задачах, не на шаблонных

## Слайд 9. L4 изнутри: конвейер + MCP

**Тезис:** агент вызывает инструменты, как разработчик вызывает команды
**Визуал:** диаграмма «Аналитик (план) → Писатель (61 функция) → Критик (MCP run_tests/coverage,
1 цикл правок) → 421 passed, 100/100, 5/5»; под ней плашки MCP-инструментов: run_tests, coverage,
read_source, bug_scan
**Что осталось команде:** план тестирования для ревью · лог правок критика (нашёл противоречие
в плане) · переиспользуемые MCP-инструменты (подключаются в ZCode/CI одной строкой) · разделение ролей

## Слайд 10. Когда какой уровень применять

| Ситуация | Уровень | Почему |
|---|---|---|
| Разовый вопрос, черновик | L0 чат | нулевой порог входа |
| Массовая однотипная задача | L1 API | дёшево, воспроизводимо, CI-ready |
| Повторяемая задача с проверяемым критерием | L2 мини-харнесс | цикл самопроверки за копейки |
| Работа в реальном репо | L3 топ-харнесс | агент читает/правит/проверяет сам |
| Регламентный процесс, жёсткое ревью | L4 MCP+мультиагент | артефакты, роли, инструменты |

**Рекомендация:** L3 — рабочий инструмент по умолчанию; L1 — для массовых задач; L4 — на постоянные процессы.

## Слайд 11. Ограничения (честно)

- **N=1** — по одному прогону; волатильность LLM не измерена
- **session-subagent** — прогоны моделью сессии через субагентов; токены по протоколу tiktoken,
  внутренние размышления L3/L4 НЕ учтены (реальный API-харнесс потратил бы больше)
- **Задача легковата** — чистый код влез в промпт целиком
- **Модели одного семейства** (GLM); локальный тир не прогонялся
- **Цены ориентировочные** (окт-2026)

## Слайд 12. Выводы (тёмный фон)

1. **Качество упирается в обратную связь, а не в «сильность» модели** — харнесс превращает
   неверный тест в исправленный за копейки
2. **Один прогон — центы, часы разработчика — дороже** — уровень выбирают по цене ошибки
   и повторяемости, а не по цене токенов
3. **Человек задаёт планку компактности** — REF: 60 тестов против 145–421 у AI
4. **Мультиагентность покупает процесс, а не магию** — план, лог ревью, MCP-инструменты — активы команды
