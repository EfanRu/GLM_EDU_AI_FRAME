# AI Dev Ladder: лестница способов работы разработчика с AI

Учебно-демонстрационный проект: **одна и та же задача** (генерация автотестов для
библиотеки `demo_project/ordercalc`) решается **пятью способами** — от чата до
MCP + мультиагентности. Критерии оценки зафиксированы заранее (`CRITERIA.md`),
все прогоны измерены автоматически, результаты — в таблицах, графиках, отчёте
и презентации для команды.

```
L0 чат ──► L1 прямой API ──► L2 простой харнесс ──► L3 топовый харнесс ──► L4 MCP + мультиагент
ручной     1 запрос,          цикл + 1 инструмент    агент с полным         конвейер ролей +
труд       точные токены      (запуск тестов)        доступом к проекту     стандартные инструменты
```

## Что внутри

| Путь | Что это |
|---|---|
| `SETUP.md` | **Начните здесь**: с нуля — python, пакеты, ключи, Ollama; что где взять и зачем |
| `CRITERIA.md` | Метрики и правила честного сравнения (зафиксированы до генераций) |
| `demo_project/` | Библиотека `ordercalc` под тест + 5 посеянных баг-вариантов |
| `levels/level0_chat/` … `levels/level4_mcp_multiagent/` | Каждый уровень: README «как сделать, плюсы/минусы» + рабочий код |
| `evaluation/` | `evaluate.py` (метрики прогона), `aggregate.py` (таблицы+графики), `prices.py` |
| `results/` | Прогоны `runs/*`, сводка `TABLES.md`, графики `charts/`, итоговый `REPORT.md` (в корне) |
| `presentation/` | Готовый план слайдов для команды (`PRESENTATION_OUTLINE.md`): тезисы, таблицы, ссылки на графики |
| `tools/` | MCP-клиент CLI, фейковый LLM-сервер для smoke-тестов |

## Быстрый старт (3 минуты)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install pytest coverage matplotlib tiktoken requests
python evaluation/evaluate.py --all      # пересчитать метрики имеющихся прогонов
python evaluation/aggregate.py           # таблицы + графики
```

Чтобы прогнать генерации самим — нужен API-ключ или локальная модель: `SETUP.md`.

## Главные выводы (см. REPORT.md и results/TABLES.md)

1. **Качество упирается в обратную связь, а не в «сильность» модели**: даже
   бесплатная Flash-модель в однострельном режиме дала 100% покрытия и 5/5
   пойманных багов на этой задаче — но одна «слепая» генерация оставила
   ошибочный тест, который харнесс с запуском тестов (L2+) ловит и исправляет.
2. **Цена растёт нелинейно, а выигрыш — ситуативен**: чат и API дают результат
   за ~2k входных токенов; агентные уровни тратят в разы больше и занимают
   минуты, но снимают ручной труд и самопроверяются.
3. **Человек пока задаёт планку**: эталонный ручный сьют (REF) — самая полная
   проверка при наименьшем числе тестов; AI-сьюты догоняют объёмом, а не точностью.
4. **Мультиагентность + MCP окупаются процессом, а не магией**: артефакты
   (план тестирования, лог критика) остаются в репозитории и полезны на ревью,
   а MCP-инструменты переиспользуются в CI и любых агентах.

## Статус прогонов

Прогоны в `results/runs/` выполнены моделью сессии GLM-5.3 (и GLM-5.3-Flash)
через субагентов — помечено `executor: session-subagent`, токены посчитаны по
протоколу из CRITERIA.md. Скрипты уровней позволяют воспроизвести всё с любым
ключом/моделью (включая локальные) — см. SETUP.md.
